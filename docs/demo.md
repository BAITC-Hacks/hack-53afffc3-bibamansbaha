# Демонстрация EKT Assistant — 2–3 минуты

Демо показывает сохранённую корзину **прототипа**, без заказа и оплаты. Синтетические остатки не являются данными ekt.kz.

## Подготовка

1. `npm ci`, скопировать `.env.example` в `.env.local`, оставить `CATALOG_MODE=fixture`.
2. `node scripts/create-demo-files.mjs` создаёт безопасные примеры в `.tmp/demo-files`: XLSX, DOCX, TXT, CSV, текстовый PDF, JPEG, скан PDF. Это реальные файлы для обычного парсера; веток по имени файла нет.
3. `npm run dev`, открыть `http://127.0.0.1:3000` в новой сессии браузера.
4. Для JPEG/скана отдельно нужны `OPENAI_API_KEY` и `OPENAI_MODEL`. Примеры фото содержат публичный артикул live-каталога; fixture его не содержит и честно покажет отсутствие совпадения.

## Основной сценарий

| Время | Действие | Что объяснить |
| --- | --- | --- |
| 0:00–0:25 | Загрузить `fixture-specification.csv`, распознать | Две настоящие строки: автомат C16 отсутствует, кабель запрошен на 2,5 м. |
| 0:25–0:55 | Выбрать `DEMO-C16-IN` вместо отсутствующего `DEMO-C16-OUT` | Пять критических параметров совпадают, бренд отличается. Это кандидат по данным, не сертифицированная замена. Сертификаты отсутствуют — ссылка не выдумана. |
| 0:55–1:20 | Открыть характеристики, проверить количество | Цена автомата 1950 ₸ × 2, кабеля 450 ₸ × 2,5; сумма 5025 ₸. Числа относятся к fixture. |
| 1:20–1:50 | Подготовить предложение | Корзина пока пуста. Видны состав, сумма, исключённые строки и срок предложения. |
| 1:50–2:10 | Явно подтвердить, открыть корзину, обновить страницу | Состав сохранён сервером в SQLite для этой сессии. Повтор confirm не удваивает количество. |
| 2:10–2:40 | Попытаться запросить 100 автоматов или загрузить `fixture-unit-review.csv` | Сервер отклоняет превышение остатка. Упаковки не превращаются в метры автоматически: требуется проверить единицы и исправить количество. |

## Live-вариант и границы

В локальном окружении с разрешёнными доступами задать `CATALOG_MODE=live`, перезапустить сервер. Запросить `200300285_`, проверить текущие параметры и количество, подготовить и подтвердить предложение. На проверке 23.09.2026 API возвращал 64 920 ₸ и остаток 23; это наблюдение, а не обещание будущей цены. Обнаружено противоречие тока 160/250 А; UI его раскрывает.

Поиск охватывает две страницы / 40 позиций; каталог маркирован как частичный. API не сообщает единицу измерения — для файла с единицей требуется ручная проверка количества в единицах каталога. Живые аналоги не подтверждены: необходимых характеристик недостаточно. Успешная демонстрация аналогов относится к fixture.

Открыть `/embed` для same-origin виджета. Cross-origin production-встраивание и native-корзина ekt.kz требуют отдельного контракта. На вопросы об оплате/доставке ассистент показывает источники и противоречие порогов доставки.
